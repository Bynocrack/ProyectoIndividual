# ProyectoIndividual — Portafolio web (Flask + HTML/CSS/JS)

Portafolio web multipágina para presentar mi **perfil**, **proyectos**, **experiencia**, una sección de **agradecimientos/amigos** y un **formulario de contacto**.

## 🌐 Demo
- Deploy en Render: https://madueno.onrender.com/

## 🧭 Secciones (rutas)
- `/` — Sobre mí
- `/proyectos` — Mis principales proyectos
- `/experiencia` — Mi experiencia
- `/agradecimientos` — Mis amigos
- `/contacto` — Mándame un mensaje

## ✨ Características
- Navegación persistente entre páginas.
- Página de proyectos con tarjetas e imágenes.
- Página de experiencia con resumen, educación y habilidades.
- Formulario de contacto.
- Assets organizados en `static/` y vistas en `templates/`.

## 🧰 Tecnologías
- **Backend:** Python + Flask (app en `app.py`)
- **Frontend:** HTML, CSS, JavaScript
