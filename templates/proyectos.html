Banco Chanchito

BanchoChanchito es un prototipo de sistema bancario con graficos desarrollado en Java con base de datos MySQL, enfocado en el modelado de entidades centrales del dominio bancario: usuarios por rol (administradores/empleados/clientes), cuentas y transacciones. El objetivo es demostrar una base sólida de persistencia y control de datos para operaciones típicas del negocio (registro y trazabilidad de movimientos).

Pagina portafolio

Desarrollé un portafolio web estático y multipágina orientado a presentar perfil profesional, proyectos y un canal de contacto. La solución usa HTML semántico, una base de estilos compartida para mantener coherencia visual y scripts en JavaScript para interacción (carrusel de proyectos y envío de formulario). Integra navegación persistente, diseño dark con fondo visual y enlaces directos a GitHub como principal punto de conversión.
